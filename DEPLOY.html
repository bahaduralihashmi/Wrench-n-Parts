Deployment Guide — Website Ko Live Kaise Karein

Follow karo aur 30 minute me website live!

Deployment Overview

Aapko ye 5 steps complete karne hain:

  1. Domain + Hosting kharido (~Rs. 200/month)
  2. Database export karo localhost se
  3. Database banao hosting pe
  4. Files upload karo hosting pe
  5. Import + Config karo — LIVE!
Time: 20-30 minutes | Difficulty: Easy | Cost: ~Rs. 200/month
1
Domain + Hosting Kharido

Ye sabse pehla step hai. Aapko ek domain name (jaise wrenchnparts.com) aur hosting (website rakhne ki jagah) chahiye.

Recommended: Hostinger — sasta, easy, PHP 8.2 support

Kaise kharidein:

  • Browser me jao → hostinger.in kholein
  • "Web Hosting" pe click karein → "Single Web Hosting" chunein (~Rs. 149/month)
  • Period chunein: 12 months (sabse sasta)
  • Domain name register karein (example: wrenchnparts.com)
  • Account banayein → Payment karein (UPI/Card se)
  • Email aayegi usme cPanel login details honge

Important: Payment ke baad email check karo — usme cPanel URL, username, password hoga. Ye save karo!

2
Database Export Karo (Localhost Se)

Apni localhost (XAMPP) database ka backup banao — hosting pe import karne ke liye.

METHOD 1 phpMyAdmin Se (Easy)

  • Browser me kholo: http://localhost/phpmyadmin
  • Left panel me wrench_parts_db click karo
  • Upar "Export" tab pe jao
  • Format: SQL rakhein
  • "Go" button dabao
  • File download hogi: wrench_parts_db.sql

METHOD 2 PowerShell Se

# PowerShell open karo (Run as Admin) aur ye command chalao: C:\xampp\mysql\bin\mysqldump.exe -u root wrench_parts_db > "E:\Wrench_n_Parts.sql" # Export ho gaya! File E drive pe save hogi.
Export ke baad: SQL file ko Notepad++ ya VS Code me kholo aur first 2 lines DELETE karo:
# Ye 2 lines DELETE karni hain: CREATE DATABASE IF NOT EXISTS wrench_parts_db; USE wrench_parts_db; # Baaki sab rehne do, sirf ye 2 lines hatao.
3
Hosting Pe Database Banao

Ab hosting ke cPanel me database create karo.

Step-by-step:

  • cPanel me login karo (email se URL + credentials)
  • "MySQL Databases" icon pe click karo
  • Neeche "Create New Database" section me naam likho: wrench_parts_db → "Create Database" button
  • Ab "MySQL Users" section me naya user banao:
    • Username: wnp_user
    • Password: Wnp@2024Secure! (ya khud ka strong password)
    • "Create User" button
  • Ab "Add User to Database" section:
    • User select karo: wnp_user
    • Database select karo: wrench_parts_db
    • "Add" button dabao
  • Next page pe "All Privileges" checkbox ☑️ karo
  • "Make Changes" button dabao
Success! Ab aapke paas ye details hain (inhe save karo):
Database Details (Save karo — baad me lagenge): DB Host: localhost DB Name: wrench_parts_db DB User: wnp_user (ya jo banaya) DB Password: Wnp@2024Secure! (ya jo diya)
4
Files Upload Karo

Ab apni website ki sare files hosting pe upload karo.

METHOD 1 Zip + File Manager (Easy)

Pehle localhost se zip banao:

# PowerShell me ye command chalao: Compress-Archive -Path "E:\wrench and parts\babu design\babu design\Wrench_n_Parts\*" -DestinationPath "E:\Wrench_n_Parts_Live.zip" -Force # Zip file ban gayi E drive pe!

Ab hosting pe upload karo:

  • cPanel → "File Manager" kholein
  • public_html/ folder me jayein
  • "Upload" button click karein
  • "Choose File" → Wrench_n_Parts_Live.zip select karein
  • Upload hone ka wait karein
  • Upload ho jaye to "Go Back" press karein
  • Zip file pe right click → Extract
  • Extract location: public_html/
Important: Agar files public_html/Wrench_n_Parts/ folder me extract hui hain to unhe public_html/ ke root me move karein!

METHOD 2 FTP Se (FileZilla)

  • FileZilla download karo: filezilla-project.org
  • Connection details cPanel me milegi: "FTP Accounts"
  • Host: yourdomain.com | User: cPanel user | Password: cPanel pass | Port: 21
  • Right panel me public_html/ kholo
  • Left panel se sare files drag karke drop karo

Final Folder Structure:

public_html/ ├── admin/ ├── api/ ├── chatbot/ ├── css/ ├── customer/ ├── database/ ├── includes/ ├── js/ ├── management/ ├── shopkeeper/ ├── uploads/ ├── workshop/ ├── index.php ├── login.php ├── product-detail.php ├── workshop-finder.php ├── .htaccess └── ... (baaki files)
5
Database Import + Config Update

Ab do kaam karo — database import karo aur config files update karo.

A Database Import:

  • cPanel → "phpMyAdmin" kholein
  • Left panel me wrench_parts_db select karein
  • Upar "Import" tab pe jayein
  • "Choose File" → Wrench_n_Parts.sql select karein
  • Ne scroll karein → "Go" button dabao
  • Success message aayega ✅

B Config Files Update:

File Manager me jao → includes/config.php edit karo:

<?php date_default_timezone_set('Asia/Karachi'); session_start(); // === YE 4 LINES CHANGE KARO === define('DB_HOST', 'localhost'); define('DB_USER', 'wnp_user'); // cPanel se define('DB_PASS', 'Wnp@2024Secure!'); // cPanel se define('DB_NAME', 'wrench_parts_db'); // cPanel se // === YE 1 LINE CHANGE KARO === define('SITE_URL', 'https://yourdomain.com'); define('UPLOAD_DIR', __DIR__ . '/../uploads/'); $conn = new mysqli(DB_HOST, DB_USER, DB_PASS, DB_NAME); if ($conn->connect_error) { die("Connection failed: " . $conn->connect_error); } $conn->set_charset("utf8mb4"); $conn->query("SET time_zone = '+05:00'"); ?>
ALSO UPDATE: chatbot/api.php me bhi same DB credentials change karo (lines 5-8)!

C .htaccess Banao (public_html me):

RewriteEngine On # Force HTTPS RewriteCond %{HTTPS} off RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301] # Block SQL files <FilesMatch "\.(sql|md|log)$"> Require all denied </FilesMatch> # Block PHP in uploads <Directory "uploads"> <Files "*.php"> Require all denied </Files> </Directory>
